This project was developed using RISC-V Assembly in Ripes as part of a Computer Architecture course.

The program allows the user to move a cursor around an LED matrix using the D-pad and draw using different colors selected through switches.

Technologies Used

* RISC-V Assembly
* Ripes Simulator
* Computer Architecture

Features

* Move the cursor using the D-pad.
* Draw on an LED matrix.
* Select different colors using switches.
* Erase previously drawn pixels.
* Display a gray cursor when no color is selected.
* Keep previously drawn pixels on the matrix while moving the cursor.

Controls

Input	Function
D-pad	Move the cursor
Switch 0	Black (Eraser)
Switch 1	Red
Switch 2	Green
Switch 3	Blue

How to Run

1. Download and install Ripes.
2. Clone this repository.
3. Open the .s file in Ripes.
4. Configure the LED matrix and input devices.
5. Run the program using the simulator.

What I Learned

Working on this project helped me understand RISC-V Assembly, memory addressing, registers, branching, bitwise operations, and how software interacts with hardware components through a simulator.
